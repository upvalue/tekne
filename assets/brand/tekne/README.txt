Tekne icon asset pack

Approved four-row blue mark on a dark rounded-square tile.

source/ contains the editable Blender scene and original 1024px render.
png/ contains transparent-corner PNGs from 16px to 1024px.
web/ contains a multi-size ICO, browser PNGs, an opaque Apple touch icon,
and regular and maskable 192px/512px app icons.
macos/tekne.icns contains 16px through 1024px icon representations.

Use the regular PNGs for the web, project listings, and desktop artwork.
Use apple-touch-icon.png for Apple touch links. Its corners are opaque so
the operating system can apply its own mask.
Use the maskable PNGs only for manifest entries with purpose "maskable".
They have a full background and smaller artwork for system cropping.

The Blender file includes the model, materials, lighting, and camera.
Set the render output path before rendering on another machine.

Open index.html for a local preview with sizes, backgrounds, and downloads.
